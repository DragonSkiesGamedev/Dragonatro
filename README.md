## About the Mod
Dragonatro is a cosmetic mod for Balatro that **replaces Balatro's default art with dragons and fantastical creatures.** Its primary goal is to provide a fresh gameplay experience while remaining translatable for seasoned players and viable for competitive multiplayer mods. It features original characters created by myself, multiple fantasy references, and Easter eggs perfect for dragon fanatics (or players who simply want fresh art), without changing gameplay.

## Installation Instructions

To install Dragonatro, begin by creating a file named Dragonatro within Balatro's mods directory. Afterwards, download the [Latest Release](https://github.com/DragonSkiesGamedev/Dragonatro/releases) and extract its .zip file into the folder.

## Dependencies

This mod requires Lovely and SteamModded to run correctly. I haven't tested which versions specifically are required, as I'm not incredibly experienced in modding at this point. Any help here would be appreciated.
